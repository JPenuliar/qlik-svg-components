📋 About These Components

This preview showcases all available SVG status badges from the qlik-svg-components project. Each component is designed to be embedded directly into Qlik Sense tables via the backend load script.

Available SVG Files:

  • 📄 active_blue.svg - Blue shimmer animation for active states
  • 📄 active_green.svg - Green shimmer animation for active states
  • 📄 critical_red.svg - Red pulsing dot for critical alerts
  • 📄 pending_amber.svg - Amber combo animation for pending states
  • 📄 static_slate.svg - Static slate badge for completed items

Note: When using these SVG files in Qlik Sense, remember to encode hex color codes using %23 instead of # to prevent breaking the HTML string structure.
